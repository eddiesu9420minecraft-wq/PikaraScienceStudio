## 1. 做了什麼

### 新影片（只負責建立）
- 獨立的側邊欄頁面，七個區塊：基本資訊、影片內容與製作要求、章節與內容限制、敘事與擬人化角色、配音與動畫、素材、進階設定（預設收合）。右側摘要顯示會產生的成品與尚未完成的必填項目。
- 製作模式、敘事方式、畫面製作方式改為附說明的選擇卡片；欄位說明完整顯示（不截斷）；依內容區寬度自動調整（寬：雙欄；窄：單欄，欄位一欄）。
- 動畫風格預設「EP01 經典黑黃科技風」，不需要選擇。
- 「開始製作」或「建立，稍後開始」後自動前往「製作狀態」。

### 製作狀態（控制中心）
- 每部影片：封面（成品封面 → 工作樹封面 → 第一張關鍵幀 → 集數）、名稱、狀態、整體進度、目前步驟、11 個步驟的狀態與進度、已執行時間、預估剩餘時間（只有配音、渲染、品質檢查等有可靠進度時）、最新日誌、錯誤與失敗原因、成品。
- 操作依狀態出現：開始製作、暫停製作、繼續製作／從中斷處繼續、重試失敗階段、恢復目前步驟、取消製作、Agent 已完成、重新配音／重新渲染（前往單集編輯）、開啟輸出資料夾；「更多」選單：編輯影片設定、查看完整日誌、刪除影片任務、刪除影片檔案。
- 狀態來源：`productions`（階段、步驟、狀態）＋ `jobs`（工作目前的步驟與進度）＋ 工作樹中實際寫出的檔案（來源檔、旁白）。沒有新增第二套狀態，沒有用計時器模擬進度。

11 個步驟與後端的對應：

| 步驟 | 後端來源 |
|---|---|
| 資料研究 | script 階段 AI 工作；`<EP>_SOURCES.md` 已寫出＝完成（自訂腳本且不需要來源＝略過） |
| 腳本生成 | script 階段 AI 工作；`narration.json` 已有場景與句子 |
| 內容驗證 | script 階段 `check_script`、修正中、製作要求檢查結果 |
| 動畫生成 | animate 階段（通用樣板＝略過） |
| 語音生成 | voice 階段（配音工作的逐句進度） |
| 字幕對齊 | timeline 階段 |
| 分鏡設計 | visual 階段（關鍵幀＋畫面審查；需要時間軸，所以在字幕對齊之後執行） |
| 音訊混合／影片渲染／品質檢查 | final 階段同一個工作的實際步驟（時間軸→混音→渲染→品質檢查）與 `check_qa` |
| 成品輸出 | YouTube、Bilibili、封面、上架資訊、交付 |

### 擬人化科普
- 敘事方式：自動判斷（預設）、擬人化科普、一般旁白；可指定角色（名稱、概念、外觀、性格、人聲、音高）。
- 劇本提示詞：判斷主題是否適合擬人化、角色寫入 `narration.json` 的 `characters`、角色台詞加 `speaker`。動畫提示詞：共用角色元件（固定外觀）、表情、肢體動作、對話氣泡、互動。
- 配音：角色台詞使用角色的參考人聲（`tools/CosyVoice/reference` 中已有的人聲）＋音高（變調不變速）；旁白句子的快取鍵不變（既有配音不會重做）。`make_cn` 會把角色名稱與設定轉成簡體。

### 其他頁面
- v0.2「區塊＋面板」與 v0.3 卡片統一（一層卡片、標題字級、內距、圓角、陰影）；卡片內的面板改為內嵌區塊；任務佇列移除只有一個分頁的分頁列；完整腳本分頁標題一致；資源監控小卡說明不再擠在一起；預覽與發佈的縮圖卡片不再錯位。

## 5. 測試中發現並修正的問題

1. **Studio 當機後 20 秒內重新開啟，工作永遠停在「執行中」**（既有問題）：重新啟動時上一個程序的心跳還沒過期，工作被略過，之後也不再檢查。修正：執行佇列的程序每 30 秒檢查不屬於自己、心跳過期的「執行中」工作，標記中斷並重新排入。修正後情境 E 通過。
2. 取消製作後，製作狀態把「音訊混合」顯示為已取消（實際是在渲染時取消）。修正：記錄被取消的工作。
3. Sandbox 交付後保留的分支在「刪除影片任務」時沒有刪除。修正：一併刪除這次製作自己的分支（只限 `studio/auto/`）。
4. 命令列 `auto-board --id` 在讀取時自己鎖住資料庫（只影響命令列，介面的指令沒有這個問題）。
5. 介面截圖導覽在 Studio 已開啟時會把焦點交給正在執行的 Studio 後直接結束；且可能接續資料庫中的工作。修正：截圖模式不取得佇列鎖、不走單一執行個體、使用自己的 WebView 設定檔。

## 6. 尚未驗證／限制（不宣稱已完成）

- **擬人化的動畫效果沒有實測**：這次沒有呼叫 AI，所以沒有產生 AI 撰寫的角色動畫；提示詞內容有單元測試，但角色外觀一致性、表情與互動的實際品質要等真正製作一集才能確認。
- **角色人聲沒有人工試聽**：已確認角色台詞實際用角色的參考人聲與音高合成、旁白不受影響；聲音是否自然、角色是否容易分辨，需要人工試聽（`<隔離測試專案>\.studio\trash\TEST006-*\voice\`）。
- 暫停是「目前步驟做完才停」：配音、渲染等工作無法在中途安全暫停（需要立即停止時用「取消製作」，之後可從中斷處繼續，配音與已渲染的場景不會重做）。
- 預估剩餘時間只對有逐句／逐幀進度的工作顯示；AI 步驟不顯示。
- 在「製作狀態」看別的程序（例如命令列）執行的製作時，畫面靠每 4 秒重新讀取更新（同一個 Studio 執行的製作有即時事件）。
- 一次正式版截圖導覽中，視窗在中途被最小化（之後的畫面只有標題列），重跑兩次都無法重現，判斷為當時桌面上的其他操作；該次的版面檢查（DOM）仍全部完成且無問題。
- 尚未在其他電腦、其他 GPU 組合上測試；正式版未簽章。
