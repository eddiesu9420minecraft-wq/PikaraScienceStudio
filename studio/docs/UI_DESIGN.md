# UI 設計（Apple 風格 × Pikara 色彩）

方向：參考 macOS 的設計語言（Final Cut Pro、Xcode、系統設定），以來源清單側欄、工具列、內容區、檢閱器組成，安靜、資訊密度高。色彩只用 Pikara 的深色夜間實驗室配色，也就是影片本身的色調，讓 UI 跟成品在視覺上一致。

## 1. 資訊架構

```
Pikara Studio
├ 專案 Projects              ← 首頁：專案卡片、最近輸出
├ 〔專案名稱〕
│  ├ 腳本 Script            ← 幕／句編輯、錨點、一鍵產生提示詞、AI 改稿
│  ├ 配音 Voice             ← 語音設定檔、引擎切換、語速、逐句試聽與重生
│  ├ 時間軸與預覽 Timeline  ← 句子／錨點軌、Remotion 預覽（stills＋720p 預覽影片）
│  ├ 輸出 Renders           ← 版本列表（繁／簡、30/60fps、1.5x）、QA 報告
│  └ 發佈 Publish           ← 檢查清單、中繼資料、核准、手動發佈後回填網址
├ 佇列 Queue                ← 全域工作佇列、排程時段
├ 資源 Resources            ← GPU/VRAM/NVENC/溫度/CPU/RAM/Disk 即時圖表
├ 環境 Doctor               ← 檢查、修復、授權確認
└ 設定 Settings             ← 工作區、AI（API key／CLI）、語音預設、排程、Git
```

## 2. 版面格線

- **基本單位 4pt**，間距只用 4／8／12／16／24／32／48。
- 視窗最小尺寸 1180×720，建議 1440×900。
- 三欄：**側欄 232px**（可收合到 56px 只顯示圖示）｜**內容區 flex**｜**檢閱器 320px**（可隱藏，⌥⌘I／Ctrl+Alt+I）。
- 工具列高 52px，標題列跟工具列合併（Tauri `decorations:false` 時自繪標題列，Windows 上保留原生的最小化／最大化／關閉三鍵區）。
- 內容區的最大可讀寬度 880px（腳本編輯器），表格與時間軸則填滿寬度。
- 圓角：視窗內的面板 10px、按鈕 6px、標籤 4px。**不做卡片堆疊**：清單使用分隔線，不用一張張卡片。

## 3. 字體

Windows 上不使用 SF Pro（其授權限 Apple 平台）。改用 `"Segoe UI Variable Text", "Noto Sans TC", "Noto Sans SC", system-ui`；程式碼與數字用 `"Cascadia Mono", "Noto Sans Mono", monospace`；數字欄位設定 `font-variant-numeric: tabular-nums`。

| Token | 尺寸／行高／字重 | 用途 |
|---|---|---|
| `title1` | 26/32/600 | 頁面標題 |
| `title2` | 20/26/600 | 區段標題 |
| `headline` | 15/20/600 | 清單主文字、對話框標題 |
| `body` | 14/20/400 | 一般內文、腳本編輯 |
| `callout` | 13/18/400 | 說明、檢閱器 |
| `caption` | 12/16/400 | 標籤、時間碼 |
| `mono` | 13/18/400 | log、指令、路徑 |

## 4. 色彩（來自 `src/theme/palette.ts`）

| UI Token | 值 | 對應 palette | 用途 |
|---|---|---|---|
| `bg.window` | #090D18 | `ink` | 視窗底色 |
| `bg.sidebar` | #0F1626（加 80% 不透明度＋背景模糊，Windows 11 可用 Mica） | `night` | 側欄 |
| `bg.content` | #151E33 | `wall` | 內容區 |
| `bg.elevated` | #1C2740 | `wallLight` | 檢閱器、彈出視窗、選取列 |
| `separator` | #2A3654 | `line` | 1px 分隔線 |
| `text.primary` | #EEF1F7 | `paper` | 主要文字 |
| `text.secondary` | #8A97B4 | `mist` | 次要文字 |
| `accent` | #FFB547 | `amber` | 主要按鈕、選取、焦點環、品牌 |
| `accent.pressed` | #E08A1E | `amberDeep` | 按下狀態 |
| `info` | #5CC8FF | `ice` | 執行中、資料流、連結 |
| `info.deep` | #2C7FD0 | `iceDeep` | 進度條底 |
| `success` | #7FE0C2 | `mint` | 成功、QA 通過 |
| `warning` | #FFB547 | `amber` | 警告（加上 ⚠ 圖示，與 accent 區分） |
| `danger` | #FF6B6B | **新增（只用於 UI）** | 失敗、刪除。palette 沒有紅色，這是 UI 專用的新 token，不得用在影片中 |

- 主要按鈕：amber 底配 ink 字（對比 11.0:1，已計算）。次要按鈕：透明底、`separator` 外框、paper 字。
- 焦點環：2px amber 外框加 2px 外距（鍵盤操作時才顯示，使用 `:focus-visible`）。
- 只提供深色模式（v1.0 前不做淺色）。

## 5. 元件清單

`Sidebar/SourceList`（群組標題、項目、徽章計數）、`Toolbar`（分段控制、搜尋欄、主要動作）、`Inspector`、`SegmentedControl`、`Button`（primary／secondary／destructive／plain）、`IconButton`、`TextField`、`TextArea`（腳本用，支援 IME）、`Stepper`（語速）、`Slider`（語速 0.5–2.0，每格 0.05）、`Toggle`、`Popover`、`Sheet`（從頂部下拉的對話框，用於確認與授權）、`Alert`、`Toast`（右下角，5 秒）、`ProgressBar`（確定／不確定）、`ProgressRing`（側欄徽章）、`Table`（可排序、選取）、`Waveform`（Canvas，逐句）、`TimelineTrack`（句、錨點、幕界）、`VideoPlayer`（`<video>` 透過 Tauri asset protocol 播放本機 mp4）、`Sparkline`／`LineChart`（資源）、`StatusDot`（ok／warn／fail／running）、`LogView`（虛擬捲動、等寬字、篩選等級）、`DiffView`（AI 修改預覽）、`Checklist`（發佈）、`EmptyState`。

## 6. 互動狀態

| 狀態 | 表現 |
|---|---|
| hover | 背景 +4% 亮度（`bg.elevated` 8% 疊加），120ms |
| pressed | 背景 +8%，主要按鈕改用 `accent.pressed` |
| focus | amber 焦點環 |
| disabled | 不透明度 40%，並以 tooltip 說明原因（例如「GPU 使用中：渲染 EP01 進行中」） |
| running | ice 色的不確定進度條，加上脈動的狀態點（`prefers-reduced-motion` 時改為靜態） |
| success／fail | mint／danger 的狀態點，加上 toast；失敗的 toast 有「查看 log」「交給 Doctor」按鈕 |
| dirty（未儲存） | 標題後顯示 •，⌘S／Ctrl+S 儲存並 commit |
| locked | 有渲染使用該集時，腳本編輯器為唯讀，並顯示橫幅：「渲染中，修改會在下次渲染生效」→ 可以「另存為草稿分支」 |
| destructive | 一律跳出 Sheet 二次確認，說明影響範圍；刪除＝移到資源回收筒 |

動畫：只用 opacity／transform，120–220ms，`cubic-bezier(.2,.8,.2,1)`。不使用彈跳或發光效果。

## 8. 無障礙與在地化

- UI 文字放在 `i18n/zh-TW.json`、`zh-CN.json`（UI 語言與影片 locale 分開設定）。
- 所有圖示按鈕都要有 `aria-label` 與 tooltip；全部操作都可以用鍵盤完成；對比至少 4.5:1（已計算：mist #8A97B4 疊在 wall #151E33 上 5.66:1，疊在 wallLight #1C2740 上 5.07:1，都通過 AA）。
